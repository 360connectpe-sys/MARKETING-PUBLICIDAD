# 360 Connect – Tienda web

Página web de **360 Connect** (placas NFC + QR para Google, TikTok, Instagram y WhatsApp).

- `index.html` → toda la página. Para cambiar **precios, productos, packs, el plan o el número de WhatsApp**, busca la sección `CONFIGURACIÓN` al inicio del `<script>`.
- `img/` → fotos de productos, logo y la mascota Connecti.

El carrito envía el pedido como mensaje al WhatsApp 974 337 299. No tiene pasarela de pago.
La demo del "Plan Connect Pro" (menú, redes, juego y ranking) es una simulación dentro de la página.
